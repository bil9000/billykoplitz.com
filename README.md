# billykoplitz.com

A public mirror of **https://billykoplitz.com**: the contents of its S3 bucket, file for file.

- The site is written in Publii and hosted on S3 + CloudFront. This repo holds the rendered output, not the Publii source.
- Each commit is a snapshot of the live site on the date in its message. Git history shows every change from one snapshot to the next.
- The Internet Archive's Wayback Machine has excluded this domain, so this repo serves as the public archive.
